# V17 extended MiniSAT run at 600 seconds (2026-11-07)

This is a targeted continuation of the audited V17 configuration. It reruns only the 13 pairs that were not proven by V17 at 300 seconds:

- `infsteps180`: 4 pairs;
- `cont`: 9 pairs.

The run used the same V17 source and binary, MiniSAT 2.1.0, 6,000,000 KB per process, and a 600-second instance cutoff. Four workers were used only to shorten wall-clock time; each solver process received the same single-instance configuration. No CaDiCaL process was started.

All 13 pairs reached the 600-second SAT deadline. No new optimum was proven, no cost or bound was reported for a timeout, and the independent audit passed. Therefore coverage remains `(72, 68, 63) = 203/216`; this round is diagnostic evidence that increasing the cutoff alone is insufficient.

`launch_state.json` records source and binary provenance. The raw per-instance JSON and logs remain under `w1`–`w4`. `summary.csv`, `independent_audit.json`, and `archive_hashes.json` are generated by `audit_archive.py`.
